# 🛍️ S&A Treasures - Order Management Automation

S&A Treasures-এর ওয়েবসাইট থেকে আসা কাস্টমার অর্ডারগুলোর ডেটা স্বয়ংক্রিয়ভাবে গুগল শিটে (Google Sheets) সংরক্ষণ করা এবং কাস্টমারকে একটি চমৎকার ব্রান্ডেড কনফার্মেশন মেইল পাঠানোর জন্য এই অটোমেশন সিস্টেমটি তৈরি করা হয়েছে। 

এটি ব্যাকএন্ড হিসেবে **Google Apps Script (V8 Engine)** এবং ফ্রন্টএন্ডের সাথে ডেটা আদান-প্রদানের জন্য **CORS-enabled REST API Architecture** ব্যবহার করে।

---

## ✨ বৈশিষ্ট্যসমূহ (Features)

*   **⚡ রিয়েল-টাইম ডেটা সিঙ্ক:** ওয়েবসাইট থেকে অর্ডার প্লেস হওয়ার সাথে সাথে গুগল শিটে ডেটা জমা হয়।
*   **🆔 ইউনিক অর্ডার আইডি জেনারেট:** প্রতিটি অর্ডারের জন্য একটি ইউনিক আইডি (যেমন: `SAT-123456`) অটো-জেনারেট হয়।
*   **💰 অটোমেটেড কমিশন ক্যালকুলেশন:** মোট বিলের ওপর ভিত্তি করে ১০% (`0.10`) এফিলিয়েট/স্টাফ কমিশন স্বয়ংক্রিয়ভাবে হিসাব করে শিটে বসে।
*   **✉️ ব্রান্ডেড ইমেইল নোটিফিকেশন:** কাস্টমারের মেইলে অর্ডারের বিবরণীসহ (অর্ডার আইডি, প্রোডাক্ট, বিল, অ্যাড্রেস) একটি প্রিমিয়াম পার্পল-থিমযুক্ত HTML ইনভয়েস মেইল চলে যায়।
*   **🔒 CORS এবং এরর হ্যান্ডলিং:** ব্রাউজারের CORS পলিসি ব্লক এড়াতে কাস্টম হেডার সাপোর্ট এবং যেকোনো ফেইলর ট্র্যাকিংয়ের জন্য ট্রাই-ক্যাচ (`try-catch`) মেকানিজম।

## 📊 গুগল শিট কলাম বিন্যাস (Google Sheet Architecture)

স্ক্রিপ্টটি আপনার একটিভ গুগল শিটের প্রথম ওয়ার্কশিটে নিচের সিকোয়েন্স অনুযায়ী **A থেকে L কলামে** ডেটা ইনসার্ট করে:

| কলাম | ফিল্ডের নাম (Field Name) | বিবরণ (Description) |
| :--- | :--- | :--- |
| **A** | Date | অর্ডার সাবমিট করার তারিখ ও সময় |
| **B** | Order ID | অটো-জেনারেটেড ইউনিক আইডি (`SAT-XXXXXX`) |
| **C** | Name | কাস্টমারের নাম |
| **D** | Phone | কাস্টমারের মোবাইল নম্বর |
| **E** | Address | ডেলিভারি ঠিকানা |
| **F** | Products | অর্ডার করা পণ্যসমূহের তালিকা |
| **G** | Total Bill | মোট বিলের পরিমাণ (টাকা) |
| **H** | Advance | অগ্রিম পেমেন্টের পরিমাণ |
| **I** | Payment Ref | পেমেন্ট রেফারেন্স বা ট্রানজেকশন আইডি |
| **J** | Staff Code | রেফারেল বা স্টাফ কোড |
| **K** | Commission | ১০% হারে হিসাবকৃত কমিশন অ্যামাউন্ট |
| **L** | Email | কাস্টমারের ইমেইল অ্যাড্রেস |

## 🛠️ সেটআপ এবং ডিপ্লয়মেন্ট গাইড (Setup & Deployment)

### ১. গুগল অ্যাপস স্ক্রিপ্ট কনফিগারেশন
1. আপনার গুগল শিটটি ওপেন করুন।
2. মেনুবার থেকে **Extensions > Apps Script**-এ যান।
3. এডিটরে থাকা আগের সব কোড মুছে `Code.gs` ফাইলে আমাদের ফিক্সড করা নতুন `doPost(e)` কোডটি পেস্ট করুন।
4. উপরে থাকা **Save (ফ্লপি ডিস্ক আইকন)**-এ ক্লিক করুন।

### ২. ওয়েব অ্যাপ হিসেবে ডিপ্লয় (Crucial Step)
1. স্ক্রিপ্ট এডিটরের ডানদিকের উপরে **Deploy > Manage deployments**-এ ক্লিক করুন।
2. **Edit (পেন্সিল আইকন)**-এ ক্লিক করুন।
3. **Version** ড্রপডাউন থেকে অবশ্যই **New version** সিলেক্ট করুন।
4. **Who has access** অপশনটি **Anyone** সেট করুন।
5. **Deploy** বাটনে ক্লিক করুন।
6. স্ক্রিপ্টটি আপনাকে একটি **Web App URL** দিবে, সেটি কপি করে নিন।

### ৩. ফ্রন্টএন্ড ওয়েবসাইট কানেকশন
